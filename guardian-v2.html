Guardian Live V2 · Local demonstration

Guardian Live V2 added a Gradio interface for video uploads and recorded webcam clips, segmented activity analysis, Guardian-O decisions, a timestamped timeline, and JSON/CSV exports.

What changed

Instead of treating a clip as a single prediction, the local application presented multiple sampled windows and marked them ACCEPT or REVIEW. The interface reported model and probe inference times, activity labels and score changes.

Why V3 followed

A working dashboard is not evidence that a reliability score is statistically effective. V3 evaluated frozen monitor configurations against a baseline with controlled data and uncertainty estimates.

Limitations

The V2 implementation was a local Python/Gradio application, configured for 127.0.0.1:7861. This static website does not run it. Its version-specific accuracy and latency have not been independently established here. The original files must pass source, licensing and execution review before publication.
